## C. How to add an asset

1. Put the original in the folder shown above (do not rename existing files).
2. For images used in scenes, add an entry to `scripts/optimize-assets.mjs` and run `npm run assets`.
3. Point the component or data file at the new `/images/web/...` path (or upload gallery/blog media in the CMS).
